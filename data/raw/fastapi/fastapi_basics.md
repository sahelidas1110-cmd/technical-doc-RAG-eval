
# FastAPI Fundamentals

FastAPI is a Python framework for building
modern web APIs.

## API Endpoints

An API endpoint is a specific URL where
a client can interact with an application.

FastAPI supports HTTP methods such as GET,
POST, PUT, and DELETE.

## Request Validation

FastAPI uses Python type hints and Pydantic
models to validate incoming request data.

## Automatic Documentation

FastAPI automatically generates interactive
API documentation using OpenAPI and Swagger UI.
