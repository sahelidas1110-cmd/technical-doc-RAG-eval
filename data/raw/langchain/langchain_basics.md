
# LangChain Fundamentals

LangChain is a framework for developing
applications powered by large language models.

## Document Loaders

Document loaders are responsible for loading
data from different sources such as PDFs,
text files, web pages, and databases.

## Text Splitters

Text splitters divide large documents into
smaller chunks.

Chunking is important because LLMs have context
window limitations and retrieval systems work
with smaller pieces of information.

## Embeddings

Embeddings represent text as numerical vectors.

Semantically similar text generally has similar
vector representations.

## Retrievers

Retrievers search for relevant documents
based on a user query.

They are an important component of
Retrieval-Augmented Generation systems.
